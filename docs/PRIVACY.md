# BumpPump · 泵碰 隐私说明

本机保存饮食、训练、测量、食品标签、动作、目标、最近移除记录和对话历史。数据目录为用户 Library/Application Support/app.bumppump.mac。App 不自动读取其他软件的数据。

API Key 使用本机 AES-GCM 加密保存，安装密钥与密文受文件权限保护；不是系统钥匙串，也不需要每次启动输入电脑密码。能访问该用户本机文件的程序仍可能访问这些文件。

用户主动发送消息或测试连接时，App 直接请求所选 AI 服务商。发送内容可能包含对话、所选图片/文本/PDF内容及工具查询到的相关健身记录。该处理受相应服务商政策约束，并可能消耗其 API 额度。手动记录不需要 AI 请求。

附件仅处理用户明确选择的文件；图片缩小后转成不含原始 EXIF 的 JPEG，PDF只提取支持范围内的文字。对话和附件保存在本机，导出记录不包含密钥或聊天。

检查版本只在用户配置 GitHub 仓库并主动点击时请求 GitHub。App 没有项目方中转服务器、广告 SDK 或分析 SDK。公开仓库的反馈区不要提交个人记录、聊天、附件或密钥。
